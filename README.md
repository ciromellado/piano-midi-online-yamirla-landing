# 🎹 Piano Midi online | Yamirla Piano PWA-3

> **Adiós a los VST pesados | Llegó la Revolución Web**

Landing page oficial de **Yamirla Piano PWA-3**, una plataforma web que revoluciona la producción y ejecución musical al sustituir los pesados complementos VST por la potencia y rapidez de la **Web Audio API**.

---

## 🚀 Acerca del Proyecto

**Yamirla Piano PWA-3** transforma cualquier navegador en una estación de sonido de alta fidelidad sin necesidad de descargas kilométricas, instalaciones complejas ni sobrecarga de memoria RAM.

### 🌟 Características Principales
* ⚡ **Audio Ultraliviano:** Ejecución fluida directamente sobre Web Audio API.
* 📦 **Cero Instalaciones:** Funciona en cualquier navegador moderno sin plugins adicionales.
* 🎹 **Soporte MIDI:** Conexión e integración instantánea con teclados y controladores MIDI.
* 📱 **PWA (Progressive Web App):** Llévalo contigo en cualquier dispositivo.
* 🎥 **Demostración en Video:** Video promocional integrado que muestra la fluidez y potencia del audio web.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5 / CSS3 / JavaScript (ES6+)**
* **Tailwind CSS (via CDN)** — Diseño moderno, responsivo y elegante.
* **Web Audio API & smplr** — Motor de sintetizador y procesamiento DSP en tiempo real.
* **FontAwesome** — Iconografía.
